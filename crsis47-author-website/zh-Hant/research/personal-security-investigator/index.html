CRSIS-47
Personal Security Investigatorv0.2

在受控環境下，考察當下證據到來時，評估結果會發生怎樣的變化。

實驗可行性原型 · 並非經過驗證或用於生產的入侵偵測系統。

目的方法論檢查點評估可追溯性限制

01 / 研究問題

重新評估。
保留推理過程。

Personal Security Investigator 和 v0.2 是一款基於本機瀏覽器的測試工具，用於探索漸進式證據揭露。它提供了一個虛構場景、定時發布的證據包，以及一種允許調查人員記錄安全評估隨時間推移發展過程的方法。

其目的是檢驗過程的可行性和可用性：資訊何時變得合格，調查人員得出什麼結論，結論為何發生變化，以及如何將現有證據追溯到每個已保存的評估。

本次評測版本不會掃描設備、連接帳戶或產生獨立的安全性判斷。其評估結果由人工操作員輸入。本文不報告任何研究結果、檢測性能評估或功效聲明。

02 / 實驗方法

建議的工作流程。
有界原型。

預期的可行性工作流程採用固定的虛構場景，並計劃發布六次證據。這是對原型和建議研究方法的描述，並非證明已完成經過驗證的實驗。

  1. 定義運行。 開始之前，請確定場景、版本、調查員角色、時鐘模式和記錄程式。
  2. 建立 T+0。 首先，請提供第一份證據包。 T+0 並非指涉嫌入侵的開始時間、案件立案時間或評估文件保存時間。
  3. 逐步公佈證據。 僅審查當前場景檢查點適用的資料。預期介面提供受控的單步執行和即時調度；v0.2 中的時脈模式佈線仍是一個開發問題。
  4. 記錄並重新評估。 保存分類和理由，並說明不確定性和其他可能的解釋。隨著更多證據的出現，重新審視這個判斷。
  5. 保留記錄。 匯出運行和檢查點歷史記錄以供內部審查。在使用記錄支持研究結論之前，請定義評分、計時規則和驗證程序。
03 / 逐步揭露證據六部計劃發行作品

證據時鐘。

場景時間

確定包裹何時符合審核條件。

掛鐘時間

衡量實際執行時間。它必須與場景時間和暫停時間區分開來。

檢查點 - 節省時間

記錄調查員保存評估報告的時間；這種情況可能發生在預定發布之後。

單步運行並非 47 秒的實際運行時間檢測結果。瀏覽器調度、後台標籤頁限速以及未解析的時鐘行為都會限制時間解讀。

04 / 調查員評估

結論。
以及它的解釋。

MALICIOUS
調查人員認為已公佈的證據支持惡意解讀。
BENIGN
調查人員判斷已公佈的證據是否支持合理的解釋。
UNCERTAIN
現有證據不足以做出足夠明確的解釋。

這些分類由調查人員輸入，並非自動偵測或經核實的真實結果。該介面還允許選擇性地輸入主觀入侵機率和置信度估計值。這些是不同的字段；兩者都未經校準。

必須提供理由說明。理由說明應將評估結果與已發表的證據聯繫起來，區分觀察結果和推斷結果，指出尚未解決的問題，並考慮其他可能的解釋。評估結果的變更應與先前的記錄相符，並能被理解。

05 / 可追溯性與審計記錄

有哪些可供選擇。
結論是什麼？

原型系統將已儲存的評估結果與已發布證據包的識別碼以及發布日誌的快照關聯起來。記錄包括分類、理由、可選的機率和置信度、場景時間、保存時間戳記以及實際經過時間。發布記錄區分計劃發佈時間和已記錄發佈時間；暫停和恢復操作分別記錄在單獨的日誌中。

此介面提供運行 JSON 和檢查點 CSV 匯出功能。後續版本不會透過常規介面覆蓋先前的評估結果。這是一個記憶體歷史記錄，並非防篡改或獨立安全的審計帳本。刷新或關閉頁面可能會遺失即時狀態，因此需要明確匯出才能儲存。

私人研究文件（包括方案、版本歷史記錄、方法、驗證計劃和實驗記錄）與網站分開保存。工作原型、場景有效載荷和原始研究記錄均不在此處託管或提供下載。

06 / 限制與發展現狀

可行性第一。
驗證工作仍有待完成。

研發狀態：實驗性 v0.2

  • 提供的軟體包僅包含一個虛構場景，無法證明其在典型的惡意和良性情況下均能保持效能。
  • 評估結果由人工輸入。此原型系統無法獨立驗證資訊來源、偵測安全漏洞或展示自主回應能力。
  • 原始碼檢查發現時鐘模式初始化不完整：選擇器未一致地進入運行狀態並匯出協定元資料。暫停時間統計也需要修正和驗證。目前，計時比較尚不合理。
  • 證據門控是一種呈現機制。後續的軟體包內容會捆綁在本機用戶端原始碼中，因此這並非安全或匿名的證據交付方式。
  • 本地導出和介面歷史記錄本身並不能建立加密完整性、持久性儲存、獨立審查或可重現性。
  • 目前尚未證實其通過獨立驗證、具備已校準的機率或達到正式使用條件，也未證明其偵測效能有所提升。

計劃驗證

下一步工作包括解決時鐘和記錄一致性問題、測試發布資格和快照保存、確定可審查的方案和場景集、預先聲明評分和排除標準，以及透過獨立審查評估可重複性。這些步驟屬於計劃工作，並非已完成的驗證。
