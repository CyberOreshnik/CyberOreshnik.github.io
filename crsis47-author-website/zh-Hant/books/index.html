書 01認知

The 47-Second Question

認識到決策問題。

當真相一點一點浮出水面，而我們又不能再拖延做出決定時，會發生什麼事？

當損害顯現時，幹預的機會可能早已錯過。 《The 47-Second Question》以這種令人不安的空白開篇，並跟隨主角Constantin Jean-Pierre，探尋一個縈繞心頭的問題：究竟何時才能有人知曉？證據零零散散地出現。警報可能具有誤導性。等待是有代價的。本書是KNOW出版社T+47系列的第一部，探討如何在不將緊迫感作為錯誤藉口的情況下識別危險。

書 02推理

When the Evidence Changes

隨著證據的出現而修改判決。

當新的證據挑戰了大家普遍認為正確的結論時，會發生什麼事？

警報正確，但結論未必正確。 When the Evidence Changes 講述的是這樣一個令人不安的時刻：缺失的背景資訊動搖了原本看似顯而易見的答案。機器對它已視為威脅的人有什麼責任？分析師對證據又負有什麼責任？在 T+47 的第二階段「理性」中，讓-皮埃爾直面最初答案的誘惑——以及改變它所需的勇氣、自律和責任感。

書 03行動

The Machine Has the Keys

審查授權行為和控制權。

當智慧系統掌握了鑰匙，誰來為它們打開的大門負責？

警告旨在引起重視。行動則能改變人生。 The Machine Has the Keys 跨越了識別危險與授權智慧系統做出回應之間的界限。透過個人反思和示例性的安全場景，讓-皮埃爾直面最重要的保障措施：誰能停止機器、撤銷其決策或撤銷其權限？在 T+47 的第三階段 ACT 中，這些關鍵要素成為人類無法輕易放棄的責任。

書 04直面

The Other Machine Has Keys Too

考慮對抗性和競爭性的機器代理。

當另一台機器擁有挑戰第一台機器的權限時會發生什麼？

你的機器已經學會如何應對。另一台機器正在學習如何應對。 The Other Machine Has Keys Too超越了單一系統的權威，進入了一場觀察、適應和相互競爭的決策的博弈。在這種融合了推測敘事和分析的局面中，防禦性舉動反而會成為對方的訊息。 T+47的第四階段「對抗」提出了這樣一個問題：當兩個智慧系統都能改變對手的選擇時，誰該承擔責任？

書 05人的判斷仍然至關重要。

The Cost of Waiting

人的判斷仍然至關重要。

證據不完整時，等待的代價是什麼？

決定並非總能等到真相完整呈現。在教授的全球虛擬課堂裡，學生們面對網路安全、醫療、金融市場和情報領域中證據不全所帶來的人間後果。行動過早可能造成傷害，等待過久也有代價。The Cost of Waiting 將 T+47 帶入這些選擇之間：不確定性要求審慎判斷，而責任始終由人承擔。
