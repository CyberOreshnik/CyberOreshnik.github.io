The Machine Has the Keys

Constantin Jean-Pierreによる

インテリジェントシステムが鍵を握っている場合、それらが開く扉の責任は誰が負うのだろうか？

あらすじ

機械は動き出す準備が整った。誰が許可を与えたのか？そして、次に何が起こるのか、誰が責任を負うのか？

The Machine Has the Keysは、説得力のある評価が重大な権力へと転化する地点から始まる。危険を特定できるシステムは、業務の中断、アクセス制限、あるいは他者の選択の変更を許される場合もある。行動能力があるからといって、それが許可されるかどうかは決まらない。正しかったとしても、ブレーキの必要性がなくなるわけではない。

Constantin Jean-Pierreは、個人的な考察と具体的なセキュリティ運用シナリオを通して、能力だけでなく責任の重要性を説きます。システムを停止できるのは誰か？どの権限をアクセスできないようにすべきか？操作を元に戻すことは可能か？システムが誤った動作をした場合、相手側にはどのような影響があるのか​​？そして、誰が権限を取り戻す権限を持っているのか？

ACT（T+47の第3段階）では、証拠と推論は、制御、可逆性、説明責任の問題へと変わります。これらのシナリオは思考実験であり、自律的なCRSIS-47能力の実証ではありません。そのプレッシャーは人間の意思決定にかかります。つまり、統治責任を放棄することなく、何を委任できるのか、ということです。
