T+47 / 04 — 向き合う

本 4 · 向き合う

The Other Machine Has Keys Too

Constantin Jean-Pierreによる

別の機械が最初の機械に挑戦する権限を持つようになった場合、何が起こるのでしょうか？

あらすじ

危険を監視する機械は、同時に監視されている。その反応は、他者にとっての証拠となる。その優位性は、相手システムが適応するまでしか続かないかもしれない。

The Other Machine Has Keys Tooは、T+47を、単一のインテリジェントシステムの認可という問題を超えた領域へと導きます。思索的な物語と分析的な考察を通して、Constantin Jean-Pierreは競合するシステムを同じ意思決定の場へと導き、観察、応答、学習、そして互いの権限の境界への挑戦を促します。

防御行動は、本来解決しようとしていた事態を変質させてしまう可能性がある。2つのシステムはそれぞれ独自の指示に従う一方で、周囲の人々にはどちらの指示でも解決できない葛藤を残してしまう。権限が重複する場合、誰が決定権を持つのか？機械的なスピードで下される決定が、組織的、人間的な境界を越える場合、誰が責任を負うのか？

シリーズの第4段階CONFRONTでは、鍵を持つことから、同じく鍵を持つ別の知性と向き合うことへと問いが移ります。描かれるのは思考のための例示的なシナリオであり、CRSIS-47の実証研究の結果ではありません。本書は技術競争の奥にある、より難しい問いを読者に投げかけます。どの機械も全体を制御できないとき、人はどうすれば判断力、抑制、説明責任を保てるのでしょうか。
