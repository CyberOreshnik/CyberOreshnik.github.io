书 01认知

The 47-Second Question

认识到决策问题。

当真相一点一点地浮出水面，而我们又不能再拖延做出决定时，会发生什么？

当损害显现时，干预的机会可能早已错过。《The 47-Second Question》以这种令人不安的空白开篇，并跟随主人公Constantin Jean-Pierre，探寻一个萦绕心头的问题：究竟何时才能有人知晓？证据零零散散地出现。警报可能具有误导性。等待是有代价的。本书是KNOW出版社T+47系列的第一部，探讨了如何在不将紧迫感作为错误借口的情况下识别危险。

书 02推理

When the Evidence Changes

随着证据的出现而修改判决。

当新的证据挑战了大家普遍认为正确的结论时，会发生什么？

警报属​​实，但结论未必正确。When the Evidence Changes 讲述的是这样一个令人不安的时刻：缺失的背景信息动摇了原本看似显而易见的答案。机器对它已视为威胁的人负有什么责任？分析师对证据又负有什么责任？在 T+47 的第二阶段“理性”中，让-皮埃尔直面最初答案的诱惑——以及改变它所需的勇气、自律和责任感。

书 03行动

The Machine Has the Keys

审查授权行为和控制权。

当智能系统掌握了钥匙，谁来为它们打开的大门负责？

警告旨在引起重视。行动则能改变人生。The Machine Has the Keys 跨越了识别危险与授权智能系统做出响应之间的界限。通过个人反思和示例性的安全场景，让-皮埃尔直面最重要的保障措施：谁能停止机器、撤销其决策或撤销其权限？在 T+47 的第三阶段 ACT 中，这些关键要素成为一项人类无法轻易放弃的责任。

书 04直面

The Other Machine Has Keys Too

考虑对抗性和竞争性的机器代理。

当另一台机器拥有挑战第一台机器的权限时会发生什么？

你的机器已经学会了如何应对。另一台机器正在学习如何应对。The Other Machine Has Keys Too超越了单一系统的权威，进入了一场观察、适应和相互竞争的决策的博弈。在这种融合了推测性叙事和分析的局面中，防御性举动反而会成为对方的信息。T+47的第四阶段“对抗”提出了这样一个问题：当两个智能系统都能改变对方的选择时，谁该承担责任？
